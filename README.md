# Soylock 
Restoration of **Soylock**, because it was removed by SystemCallW. Now uses `uv`. Issues and PRs accepted for now but ill be barely online

## On maintenance
This import of Soylock is a bit buggy, so you probably have to inspect bugs in the code and fix them yourself. Its recommended if you are a python codefag since this hasnt been fully stabilized yet

## Note
- The project now uses [uv](https://docs.astral.sh/uv/) instead of python's toolkit. 
- For contributors, the main branchs commit history possibly can get rewritten so keep up to avoid merge conflicts.

## Usage:
```
uv run soylock <name>
```

UV will install the dependencies for you.
